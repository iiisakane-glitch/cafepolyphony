# Cafe Polyphony ウェブサイト

ビルド不要の静的サイトです。`index.html`、`css/`、`js/`、`img/` と既存の検索エンジン認証ファイルを、そのまま既存のホスティング先に配置できます。

- タイトル・検索向け説明・OGPを営業中の案内に更新。構造化データとサイトマップの更新日を追加・修正。

- スタッフ肩書きを「Pâtissier & SNS」に修正。
- 貸切は受付を断定せず、内容を伺って対応可否を個別に案内する表現に変更。

- 日本語・英語・簡体字・繁体字・韓国語に対応。JavaScriptが使えない場合も日本語の本文とリンクは表示されます。

- お知らせ一覧をランチ直後に独立して配置。過去のお知らせも折りたたみで保持し、写真付きの地域活動紹介とは分けています。

## 週替わりメニューの運用

週替わりメニューは、これまで通りLINE・Instagram・Xで案内します。サイトのランチ欄は最新の投稿を見に行ける常設の案内なので、毎週のサイト更新や公開日時の調整は不要です。SNSの内容をサイトへ自動取得・同期する仕組みではありません。

価格・セット内容・営業時間・リンク先が変わった場合にサイトを更新します。11/16〜20の提供画像は「掲載記録」と明示した折りたたみ欄に残し、現在のメニューとしては表示しません。新しい週の記録を残したい場合だけ、この欄を更新します。

## 画像の出典と加工

`img/web/` は、ユーザー提供の `cafepolyphony_website_images.zip` と既存の `img/` から作成しています。ランチ写真は11月7日に提供されたハンバーグランチの写真（`img/lunch-hamburg.jpg`）に差し替えました。シフォンはメニュー写真から、弁当は11月5日の画像から料理部分を切り出しました。地域活動の写真は11月1日の西区民まつりの出店記録です。人物の顔やキャラクターを主題とした写真は使用していません。

`scripts/prepare-assets.py` は、Downloads内の上記ZIPと既存の元画像から配信用画像を再作成する補助スクリプトです（Pillowが必要）。通常のサイト表示・公開にはPythonは不要です。

## 確認

`js/motion.js` は、トップとスクロール時に一度だけ表示アニメーションを加えます。JavaScriptが使えない場合も内容は表示され、「動きを減らす」設定では停止します。写真・ボタンのホバー演出はマウス操作時に適用します。

```text
node --check js/site.js
node --check js/motion.js
node scripts/check-site.mjs
python scripts/validate-site.py
python -m http.server 4173 --bind 127.0.0.1
```

`validate-site.py` はBeautiful SoupとPillowを使用します。5言語の翻訳漏れ、スマホメニュー、LINE・ホットペッパー導線、お知らせ一覧、参照先・画像寸法・OGP等をコードで検査します。

ChromeでPC・スマホの表示を確認しました。表示演出が一度だけ実行されること、動きを減らす設定の変更時に停止すること、スマホメニューの開閉、英語のページ内リンク、JavaScript無効時の本文表示も確認済みです。本番へのアップロード・Gitへのコミット・pushは行っていません。価格、営業時間、貸切の実際の受付条件は公開前に店舗で最終確認してください。検索結果の表示変更には再クロールが必要です。
